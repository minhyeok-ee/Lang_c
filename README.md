# 임베디드 C 연습 문제

임베디드/펌웨어 개발에 필요한 C 언어 기본기를 다지기 위한 연습 문제 모음입니다.
포인터, 메모리, 비트 연산 같은 C 핵심 개념부터 레지스터 조작, 링 버퍼, 통신 데이터 파싱 같은 임베디드 실전 주제까지 다룹니다.

## 구성

| 파일 | 내용 | 문제 수 | 채점 방법 |
|---|---|---|---|
| `01_output_prediction.c` | 출력 결과 예측 (포인터, static, 패딩, 매크로, 형 변환 등) | 15 | 실행 후 `solutions/01_answers.md`와 비교 |
| `02_bit_manipulation.c` | 비트 연산 함수 구현 | 12 | 자동 테스트 |
| `03_pointer_string.c` | strlen/memmove/atoi/연결 리스트 직접 구현 | 12 + 보너스 | 자동 테스트 |
| `04_embedded.c`, `04_embedded.h` | 레지스터 매크로, 링 버퍼, EDID 파싱, CRC, 디바운스, 픽셀 클럭 | 8 | 자동 테스트 |
| `05_concepts.md` | 개념 정리 질문 (volatile, ISR, 동시성, I2C/SPI/UART, 디스플레이 기초 등) | 27 | `solutions/05_answers.md` |

기타:
- `tests/` : 자동 채점 코드 (수정하지 마세요)
- `solutions/` : 모범 답안과 해설 (**문제를 먼저 풀고** 보세요)
- `check.ps1` : 컴파일과 채점을 한 번에 실행하는 스크립트 (Windows PowerShell)
- `test.h` : 테스트용 도구

## 실행 방법

C99를 지원하는 gcc가 필요합니다. (Windows에서는 MinGW 등)
이 폴더에서 PowerShell로 실행합니다.

```bash
powershell -ExecutionPolicy Bypass -File .\check.ps1 02
```

| 명령 | 동작 |
|---|---|
| `.\check.ps1 01` | 출력 예측 문제 전체 실행 |
| `.\check.ps1 01 5` | 출력 예측 문제 5번만 실행 |
| `.\check.ps1 02` | 내가 푼 02번 채점 |
| `.\check.ps1 02 -Solution` | 02번 모범 답안 실행 |

`.\check.ps1`을 바로 실행했을 때 "스크립트를 실행할 수 없습니다" 오류가 나면 위처럼 `powershell -ExecutionPolicy Bypass -File`을 앞에 붙이세요.

스크립트 없이 직접 컴파일하려면 (Linux/macOS에서도 동일):

```bash
gcc -std=c99 -Wall -I. 02_bit_manipulation.c tests/test_02.c -o t02.exe
```

채점 결과 예시:
```
[1. set_bit]
    - fail (line 9): set_bit(0x00, 0)
      expected 1 (0x1), got 0 (0x0)
  -> FAIL (1. set_bit)
...
 Result: 3 / 12 passed
```

## 추천 학습 순서

1. **01 출력 예측**: 실행 전에 각 문제의 `내 답:` 주석에 답을 먼저 적기. 틀린 문제는 해설을 읽고 이유를 설명할 수 있을 때까지 복습
2. **02 비트 연산**: 임베디드 C에서 가장 많이 쓰는 기본기. 막히면 종이에 2진수를 그려보기
3. **03 포인터/문자열**: 표준 라이브러리 없이 직접 구현해보기. 한 번은 종이에 먼저 써보고 입력하면 이해가 깊어짐
4. **04 임베디드**: 실제 펌웨어에서 자주 만나는 주제. 각 문제의 "생각해보기"도 함께 고민해보기
5. **05 개념 질문**: 답을 보기 전에 소리 내어 1분 안에 설명해보기

## 공부 팁

- 구현 문제는 **엣지 케이스**(빈 문자열, NULL, 0, 최댓값, 버퍼 가득 참)를 스스로 먼저 떠올려보세요. 실제 버그가 가장 많이 나는 부분입니다.
- 모범 답안과 풀이 방식이 달라도 테스트를 통과하면 괜찮습니다. 다만 답안 주석에 적힌 **"왜 이렇게 하는지"**는 꼭 읽어보세요.
- 다 풀었다면 해당 함수를 지우고 **시간을 재서** 다시 풀어보세요. (함수 하나당 5~10분 목표)
